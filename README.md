# タロット図鑑

78枚のタロットカード（ライダー・ウェイト版）の意味を、いつでも気軽に調べられるアプリです。

## 機能
- **図鑑**：78枚をアーカナ・スート別に閲覧、名前やキーワードで検索。正位置・逆位置・恋愛での視点を掲載。
- **1枚引く**：その場でシャッフルして1枚引く体験。結果はメモを添えて記録に保存できます。
- **記録**：これまで引いたカードとメモを振り返れる、自分だけの記録帳（ブラウザ内に保存）。

## 画像について
カード画像は1909年に発表されたパメラ・コールマン・スミスによるライダー・ウェイト版タロットの原版スキャンで、アメリカでは著作権保護期間が満了しパブリックドメインです（[equokka/tarot-json](https://github.com/equokka/tarot-json) より、MITライセンスのコードとともに利用）。

## デプロイ
GitHub Pagesでそのまま公開できます（`index.html` が起点）。ビルド不要の静的サイトです。
